# Roadmap

## 0.1.x

- Improve model/view scalability for very large scans.
- Add controlled JSON and CSV export.
- Add persisted window layout and display preferences.

## 0.2.x

- Add verified cleanup-rule providers and Recycle Bin operations.
- Add final preflight checks for changed files and explicit confirmation summaries.
- Add Windows Store, WinGet, MSI, and registry uninstall providers with dry-run previews.

## 1.0.x

- Ship a signed portable Windows release after clean-machine validation.
- Complete NVDA, JAWS, Narrator, high-contrast, and DPI acceptance testing.
