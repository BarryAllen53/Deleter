# Roadmap

## 0.1.x

- Improve model/view scalability for very large scans.
- Add persisted window layout and display preferences.

Implemented in the current development line:

- Controlled JSON and CSV export.
- Verified cleanup-rule matching and final file identity preflight.
- Recycle Bin operations with explicit confirmation and simulation mode.
- Safe uninstall command planning for registered Windows uninstallers.

## 0.2.x

- Add Windows Store, WinGet, MSI, and registry uninstall providers with isolated worker execution.
- Add signed portable artifacts after a signing certificate is supplied through GitHub Secrets.

## 1.0.x

- Ship a signed portable Windows release after clean-machine validation.
- Complete NVDA, JAWS, Narrator, high-contrast, and DPI acceptance testing.
